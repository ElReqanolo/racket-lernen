So benutzt du die Aufgaben

ZeichenBedeutung

★★mittel – mehrere Schritte oder ein kleiner eigener Gedanke

Vorgehen bei jeder Aufgabe

  1. Lies im passenden Kapitel der Übersicht nach, was du brauchst.

  2. Arbeite nach der Konstruktionsanleitung: Kurzbeschreibung, Datenanalyse, Signatur, Tests, Gerüst, Schablone, Rumpf. (In den Abschnitten 1.1–1.5 gibt es Signaturen und Tests noch nicht – dort reicht das Ausprobieren in der REPL.)

  3. Schreibe deine Lösung in DrRacket und drücke Start. Erst wenn alle Tests grün sind und nichts farbig hinterlegt ist, schau in die Lösung.

  4. Vergleiche: Oft gibt es mehrere richtige Lösungen. Wichtig ist, dass deine Tests sinnvoll sind und bestehen.

Abhaken kannst du erledigte Aufgaben direkt im Dokument (Kästchen vor der Aufgabe).

Kapitel 1: Elemente des Programmierens

Abschnitte 1.1–1.5: Ausdrücke, Zeichenketten, Bilder, lambda

Diese Aufgaben brauchen nur Ausdrücke, Zeichenketten, define, Bilder und lambda. Für Teil C und D müssen diese drei Beispielbilder im Definitionsfenster stehen:

(define s1 (square 40 "solid" "red"))               ; rotes Quadrat
(define c1 (circle 40 "solid" "green"))             ; grüner Kreis
(define p1 (star-polygon 20 10 3 "solid" "blue"))   ; blauer Stern
(define tile
  (lambda (a b)
    (above (beside a b)
           (beside b a))))

Teil A – Rechnen

Teil B – Zeichenketten

  • B4 ★★ Was passiert bei (+ "23" 42), (string-append 23 "42") und (number->string "23")? Erkläre jeweils, warum.

Teil C – Bilder

Teil D – Abstraktion mit lambda

  • D1 ★ Wende tile im Stepper an und klicke bis zum Ende durch.

  • D2 ★ Kann man das Ergebnis von tile wieder an tile übergeben? Probier es aus.

  • D4 ★★ Schreibe haus: bekommt eine Größe und eine Farbe und baut das Haus aus C2 in dieser Größe und Farbe.

  • D5 ★★ Schreibe gruß: bekommt einen Namen und liefert "Hallo, …!".

Abschnitte 1.6–1.13: Signatur, Tests, Konstruktionsanleitung

Ab hier jede Funktion nach der Konstruktionsanleitung: Kurzbeschreibung, Signatur, Tests, Gerüst, Rumpf.

  • E1 ★ Schreibe für diese Aufgaben nur Kurzbeschreibung und Signatur (noch keinen Code): a) Fläche eines Kreises aus dem Radius, b) Anzahl der Buchstaben eines Namens, c) Grußtext für einen Namen, d) Bild eines Quadrats mit gegebener Seitenlänge.

  • E2 ★ celsius->fahrenheit komplett nach Konstruktionsanleitung: F = C · 9/5 + 32. Tests für 0, 100 und −40.

  • E3 ★★ Schreibe zwei sinnvolle check-expect-Tests für tile.

  • E4 ★★ brutto: Nettopreis und Mehrwertsteuersatz in Prozent rein, Bruttopreis raus. Tests für 100 € / 19 % und 50 € / 7 %.

  • E5 ★★ Zwei Handytarife: Tarif A kostet 5 € im Monat plus 0,09 € pro Minute, Tarif B 10 € plus 0,05 € pro Minute. Schreibe tarif-a und tarif-b, abstrahiere sie dann zu handy-rechnung und schreibe beide Tarife damit neu.

  • E6 ★★★ Welche Signatur ist jeweils am genauesten? a) Anzahl der Schüler einer Klasse, b) Kontostand in Euro mit Cent, c) Temperatur in °C, d) Wurzel aus 2. Begründe kurz.

  • E7 ★★★ Baue absichtlich einen Fehler in celsius->fahrenheit ein (z. B. + 23 statt + 32). Lies die Check-Fehler-Meldung genau und erkläre, was sie sagt.

Kapitel 2: Fallunterscheidungen und Verzweigungen

  • F1 ★ xor (exklusives Oder): #t, wenn genau einer der beiden Wahrheitswerte #t ist.

  • F2 ★ vorzeichen: liefert "positiv", "negativ" oder "null".

  • F3 ★ betrag: Absolutbetrag einer Zahl mit if (ohne das eingebaute abs).

  • F4 ★★ wochenende?: Definiere eine Aufzählung wochentag (Montag bis Sonntag) und eine Funktion, die für Samstag und Sonntag #t liefert.

  • F5 ★★ schulnote: Punkte 0–100 in Note 1–6. Grenzen: ab 92 → 1, ab 81 → 2, ab 67 → 3, ab 50 → 4, ab 30 → 5, sonst 6. Teste jede Grenze.

  • F6 ★★ kartentyp: Kreditkartenkategorie aus dem Jahresumsatz: unter 5.000 € „Weiß“, unter 25.000 € „Gold“, unter 100.000 € „Platin“, sonst „Schwarz“.

  • F7 ★★★ schaltjahr?: durch 4 teilbar, aber nicht durch 100 – außer durch 400.

  • F8 ★★★ versandkosten: bis 1 kg 4,50 €, bis 5 kg 6,99 €, bis 20 kg 9,99 €; schwerer → violation. Teste den Fehlerfall mit check-error.

  • F9 ★★ Schreibe cute? aus der Übersicht nur mit if und or (ohne cond).

; F1
(: xor (boolean boolean -> boolean))
(check-expect (xor #t #f) #t)
(check-expect (xor #t #t) #f)
(check-expect (xor #f #f) #f)
(define xor
  (lambda (a b)

  (lambda (x)

Lösungen

; Z1
(define-record punkt make-punkt punkt?
  (punkt-x real) (punkt-y real))
(: punkt-verschieben (punkt real real -> punkt))
(check-expect (punkt-verschieben (make-punkt 1 2) 3 -1) (make-punkt 4 1))
(define punkt-verschieben
  (lambda (p dx dy)
    (make-punkt (+ (punkt-x p) dx)
                (+ (punkt-y p) dy))))

; Z2
(define-record rechteck make-rechteck rechteck?
  (rechteck-breite real) (rechteck-höhe real))
(: rechteck-fläche (rechteck -> real))
(check-expect (rechteck-fläche (make-rechteck 3 4)) 12)
(define rechteck-fläche
  (lambda (r) (* (rechteck-breite r) (rechteck-höhe r))))
(: quadrat? (rechteck -> boolean))
(check-expect (quadrat? (make-rechteck 3 3)) #t)
(check-expect (quadrat? (make-rechteck 3 4)) #f)
(define quadrat?
  (lambda (r) (= (rechteck-breite r) (rechteck-höhe r))))

; Z3
(: wallclock-time-later? (wallclock-time wallclock-time -> boolean))
(check-expect (wallclock-time-later? (make-wallclock-time 12 0)
                                     (make-wallclock-time 11 59)) #t)
(check-expect (wallclock-time-later? (make-wallclock-time 8 0)
                                     (make-wallclock-time 8 0)) #f)
(define wallclock-time-later?
  (lambda (a b)
    (> (minutes-since-midnight a) (minutes-since-midnight b))))

; Z4
(: wallclock-time-add-minutes (wallclock-time natural -> wallclock-time))
(check-expect (wallclock-time-add-minutes (make-wallclock-time 23 50) 20)
              (make-wallclock-time 0 10))
(check-expect (wallclock-time-add-minutes (make-wallclock-time 9 15) 30)
              (make-wallclock-time 9 45))
(define wallclock-time-add-minutes
  (lambda (wt n)
    (minutes-since-midnight->wallclock-time
     (remainder (+ (minutes-since-midnight wt) n) 1440))))   ; 1440 Minuten = 1 Tag

; Z5
(: computer-klasse (computer -> string))
(check-expect (computer-klasse (make-computer "Quad" 16 2000)) "fett")
(check-expect (computer-klasse (make-computer "Xeon" 8 500)) "Durchschnitt")
(check-expect (computer-klasse (make-computer "Cell" 4 1000)) "müde")
(define computer-klasse
  (lambda (c)
    (cond
      ((and (>= (computer-ram c) 16) (>= (computer-hard-drive c) 1000)) "fett")
      ((>= (computer-ram c) 8) "Durchschnitt")
      (else "müde"))))

; Z6
(: dillo-diät (dillo -> dillo))
(check-expect (dillo-diät (make-dillo 55000 #t)) (make-dillo 54000 #t))
(check-expect (dillo-diät (make-dillo 20500 #t)) (make-dillo 20000 #t))
(check-expect (dillo-diät (make-dillo 55000 #f)) (make-dillo 55000 #f))
(define dillo-diät
  (lambda (d)
    (if (dillo-alive? d)
        (make-dillo (max 20000 (- (dillo-weight d) 1000)) #t)
        d)))

; Z7
(define-record bruch make-bruch bruch?
  (bruch-zähler integer) (bruch-nenner natural))
(: bruch-mal (bruch bruch -> bruch))
(check-expect (bruch-mal (make-bruch 1 2) (make-bruch 2 3)) (make-bruch 2 6))
(define bruch-mal
  (lambda (a b)
    (make-bruch (* (bruch-zähler a) (bruch-zähler b))
                (* (bruch-nenner a) (bruch-nenner b)))))
(: bruch-plus (bruch bruch -> bruch))
(check-expect (bruch-plus (make-bruch 1 2) (make-bruch 1 3)) (make-bruch 5 6))
(define bruch-plus
  (lambda (a b)
    (make-bruch (+ (* (bruch-zähler a) (bruch-nenner b))
                   (* (bruch-zähler b) (bruch-nenner a)))
                (* (bruch-nenner a) (bruch-nenner b)))))

; Z8
(define-record termin make-termin termin?
  (termin-anfang wallclock-time) (termin-ende wallclock-time))
(: termine-überschneiden? (termin termin -> boolean))
(check-expect (termine-überschneiden?
               (make-termin (make-wallclock-time 9 0) (make-wallclock-time 10 0))
               (make-termin (make-wallclock-time 9 30) (make-wallclock-time 11 0))) #t)
(check-expect (termine-überschneiden?
               (make-termin (make-wallclock-time 9 0) (make-wallclock-time 10 0))
               (make-termin (make-wallclock-time 10 0) (make-wallclock-time 11 0))) #f)
; Überschneidung: a beginnt vor dem Ende von b UND b beginnt vor dem Ende von a
(define termine-überschneiden?
  (lambda (a b)
    (and (< (minutes-since-midnight (termin-anfang a))
            (minutes-since-midnight (termin-ende b)))
         (< (minutes-since-midnight (termin-anfang b))
            (minutes-since-midnight (termin-ende a))))))

Kapitel 4: Gemischte Daten

Für G1–G3 brauchst du dillo, parrot und animal aus der Übersicht (Kapitel 4.1).

  • G2 ★ run-over-animal: Gürteltiere sind danach tot, Papageien sagen danach nichts mehr (leerer Satz).

  • G3 ★★ animal-sentence: Papageien liefern ihren Satz, Gürteltiere "...".

  • G4 ★★ Formen: Records kreis (Radius), rechteck (Breite, Höhe), dreieck (Grundseite, Höhe) und gemischte Signatur form. Schreibe fläche.

  • G5 ★★ form-vergleichen: Zwei Formen rein, "equal", "smaller" oder "bigger" raus (bezogen auf die Fläche der ersten).

  • G6 ★★★ sicher-teilen: liefert den Quotienten oder einen Record fehler mit Nachricht. Schreibe dazu ergebnis->string, das beide Fälle in Text umwandelt.

  • G7 ★★★ Verkehrsverstöße: falschparken (Minuten), rote-ampel (Sekunden rot) und zu-schnell (km/h drüber) als Records, gemischt zu verstoß. Schreibe bußgeld: Falschparken bis 60 Min 20 €, sonst 35 €; rote Ampel unter 1 s 90 €, sonst 200 €; zu schnell 10 € pro km/h.

Kapitel 8: Exkurs – Induktive Beweise und Definitionen

Hier wird nicht programmiert, sondern bewiesen (außer I6). Schreibe jeden Beweis nach dem Rezept: Behauptung, Induktionsanfang, Induktionsvoraussetzung, Induktionsschluss.

  • I1 ★ Rechne die Gauß-Formel 0 + 1 + … + n = n(n+1)/2 für n = 0 bis 4 nach.

  • I2 ★★ Beweise per Induktion: Die Summe der ersten n ungeraden Zahlen ist n², also 1 + 3 + … + (2n − 1) = n².

  • I3 ★★ Beweise per Induktion: 1² + 2² + … + n² = n(n+1)(2n+1)/6.

  • I4 ★★ Wo steckt der Fehler? „Behauptung: In jeder Gruppe von n Pferden haben alle dieselbe Farbe. Anfang n = 1: klar. Schluss: Nimm n + 1 Pferde. Ohne das erste sind es n Pferde – gleiche Farbe. Ohne das letzte auch. Also haben alle dieselbe Farbe.“

  • I5 ★★★ Beweise per Folgeninduktion über u: Länge(cat(u, v)) = Länge(u) + Länge(v).

  • I6 ★★★ Schreibe in Racket vertauschen: In einem booleschen Ausdruck (Datendefinition aus der Übersicht, Kapitel 8.7) werden #t/#f und und/oder vertauscht, nicht bleibt. Prüfe mit Tests, dass (auswerten (vertauschen e)) immer das Gegenteil von (auswerten e) ist.

I2:

  • Anfang (n = 0): leere Summe = 0 = 0². ✓

  • Voraussetzung: 1 + 3 + … + (2n − 1) = n².

  • Schluss: 1 + 3 + … + (2n − 1) + (2(n+1) − 1) = n² + 2n + 1 = (n + 1)². ✓

I3:

  • Anfang (n = 0): 0 = 0·1·1/6 = 0. ✓

  • Voraussetzung: 1² + … + n² = n(n+1)(2n+1)/6.

  • Schluss:

\frac{n(n+1)(2n+1)}{6} + (n+1)^2
= \frac{(n+1)\,\big(n(2n+1) + 6(n+1)\big)}{6}
= \frac{(n+1)(2n^2 + 7n + 6)}{6}
= \frac{(n+1)(n+2)(2n+3)}{6}

Das ist die Formel für n + 1, denn 2(n+1) + 1 = 2n + 3. ✓

I4: Der Induktionsschluss funktioniert nicht für den Schritt von 1 auf 2 Pferde: „Ohne das erste“ und „ohne das letzte“ ergeben zwei Gruppen mit je einem Pferd, die sich nicht überschneiden. Es gibt kein Pferd, das in beiden Gruppen ist und die Farben „verbindet“. Der Schluss muss für jedes n gelten – hier gilt er erst ab n ≥ 2.

I5: Mit den Definitionen cat(ε, v) = v, cat(m u', v) = m cat(u', v), Länge(ε) = 0, Länge(m f) = 1 + Länge(f):

  • Anfang (u = ε): Länge(cat(ε, v)) = Länge(v) = 0 + Länge(v) = Länge(ε) + Länge(v). ✓

  • Voraussetzung: Für u' gilt Länge(cat(u', v)) = Länge(u') + Länge(v).

  • Schluss (u = m u'): Länge(cat(m u', v)) = Länge(m cat(u', v)) = 1 + Länge(cat(u', v)) = 1 + Länge(u') + Länge(v) = Länge(m u') + Länge(v). ✓
